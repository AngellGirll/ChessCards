# Исходники карт

SVG редактируются как обычные векторные изображения. Экспортируйте каждый файл в PNG размером 320×448 с прозрачностью и тем же именем в `Assets/ChessCards/Resources/ChessCards/Cards`.

- `Body.svg` — белый силуэт, который Unity окрашивает в цвет карты.
- `Face1`, `Face2`, `Face3`, `FaceSwap`, `FaceUndo`, `FaceSkip` — прозрачные накладки с рамкой, овалом, значением и символами.
- `Back.svg` — полная рубашка карты.

Лицо в игре состоит из окрашенного Body и соответствующей накладки Face. Четыре цвета задаются массивом `cardColors` в `ChessCardsApp.cs`. Игровые свойства карт не зависят от рисунка.

Надписи отрисованы шрифтом DejaVu Sans, лицензия находится в Resources/ChessCards/FONT_LICENSE.txt. Для экспорта SVG нужен установленный DejaVu Sans; игра использует уже готовые PNG. Подписи карт отрисовываются в Unity по выбранному языку.
