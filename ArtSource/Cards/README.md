# Исходники карт

Экспортируйте SVG в PNG 320×448 с прозрачностью и тем же именем в `Assets/ChessCards/Resources/ChessCards/Cards`.

- `Body.svg` — нейтральная градиентная основа. Unity окрашивает её в цвет карты.
- `Frame.svg` — золотая рамка с орнаментом.
- `Face1`, `Face2`, `Face3`, `FaceSwap`, `FaceUndo` и `FaceSkip` — объёмные символы.
- `Back.svg` — рубашка колоды.

Цифры используют DejaVu Serif. Подпись под картой в руке Unity отрисовывает по выбранному языку. Лицензия семейства DejaVu находится в `Assets/ChessCards/Resources/ChessCards/FONT_LICENSE.txt`.
