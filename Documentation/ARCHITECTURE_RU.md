# Архитектура ChessCards

```
Assets/ChessCards/
  Scenes/      Main (двор) и Match (партия)
  Prefabs/     ChessCards Runtime, Courtyard Layout, Match Layout
  Config/      GameBalance и RoyalTheme
  Core/        правила четырёх игр, колода, бот и данные прогресса
  Runtime/     переходы между сценами, сохранение, звук и отображение
  Editor/      редактор раскладки и меню Chess Cards
  Resources/   графика, шрифт и звук
```

## Настройка без кода

| Что поменять | Где в Unity | Как это работает |
| --- | --- | --- |
| Позиция доски, руки, кнопок или панели ремонта | Открой сцену и выбери `Courtyard Layout` или `Match Layout` в **Hierarchy** | В Inspector переключи **Landscape** или **Portrait**. Перетаскивай блоки на схеме, меняй ширину и доступные размеры за правый нижний угол. Окна редактируются на отдельных слоях **Preview Layer**. Точные координаты находятся в **Placements** |
| Раскладка по умолчанию для новых сцен | **Assets → ChessCards → Prefabs** | Открой нужный префаб в **Prefab Mode**. Настройки на экземпляре в сцене сохраняются как её собственные изменения |
| Оформление, иллюстрации, карты, фигуры, фон, шрифт и звук | **Chess Cards → Select Royal Theme** | Замени ссылки на ассеты или измени цвета. Если хочешь задавать шахматные фигуры отдельными текстурами, очисти поле **Chess Pieces Atlas**. В **Theme Override** на префабе раскладки можно назначить отдельную тему для сцены |
| Название двора и панели ремонта | **Royal Theme → Courtyard Labels** | У каждой надписи есть русский и английский варианты |
| Нахлёст и подъём карт | **Royal Theme → Card Hand Layout** | **Hand Spacing** задаёт расстояние между картами, **Hand Lift** — высоту подъёма |
| Награды, цены ремонта, начальная рука и состав колоды | **Chess Cards → Select Game Balance** | Измени поля **Restoration** и **Card Deck**. Новая партия получит обновлённую колоду |
| Режимы, паузы бота и настройки новых игроков | **Game Balance** | **Enabled Modes** задаёт порядок и доступность режимов, в том числе для рандома. Значения **Defaults for a New Save** применяются, пока игрок не сохранил собственные настройки |
| Режим для быстрого теста партии | **Match → Match Layout → Preview Mode** | Открой сцену `Match` и нажми **Play**. Сцена запускает партию в выбранном режиме, если он включён в балансе |

**Chess Cards → Open Courtyard Scene** открывает стартовую сцену. **Open Match Scene** открывает сцену партии. Для обычного запуска открывай `Main`. В **Build Profiles** должны быть обе сцены, первой идёт `Main`.

## Префабы и связи

- **ChessCards Runtime** хранит ссылки на тему, баланс и имена сцен. Единственный экземпляр сохраняется при переходе между двором и партией.
- **Courtyard Layout** и **Match Layout** хранят две раскладки и, при необходимости, переопределение темы. Сцены используют экземпляры этих префабов. Изменения в сцене сохраняются вместе с ней.
- **Core** не зависит от Unity. Он определяет легальность ходов, порядок применения карт и условия победы. **Runtime** использует эти правила и связывает их со сценами, вводом и сохранением. **Editor** добавляет инструменты авторинга.

Схема в Inspector показывает границы блоков. Итоговое оформление проверяется во вкладке **Game** в режиме **Play**. Интерфейс рисуется через IMGUI. Внутренняя раскладка списков, клеток и элементов внутри составных блоков формируется автоматически. У блока **Cards** редактируются положение, ширина и высота. Размер карт ограничивается полем **Hand Card Height** и доступным местом внутри блока; заголовок, подъём и подписи учитываются автоматически. Полный набор переводов и изменение правил самих игр остаются в коде.

Формат сохранения двора и пользовательских настроек совместим с предыдущей версией. При замене фоновых иллюстраций двора используй одинаковую композицию для обычного и восстановленного вида, чтобы участки ремонта совпадали.

## Игровой стол: редактирование нового оформления

Используются прежние `Match.unity`, `Match Layout.prefab` и `ChessCards Runtime.prefab`. Их GUID и связи сохранены. Карточные изображения, фигурки, фон зала и золотые украшения берутся из существующей `RoyalTheme`. Создавать сцену заново или запускать генератор не нужно.

1. Получи изменения через **GitHub Desktop → Fetch origin → Pull origin**.
2. В Unity открой **Chess Cards → Open Match Scene**.
3. В **Hierarchy** выбери **Match Layout**. Поле **Preview Mode** позволяет проверить шахматы, шашки, го или домино через **Play**.
4. Выйди из Play перед сохранением правок. Выбери **Landscape** или **Portrait** в Inspector. Перетаскивай блоки на схеме; правый нижний угол меняет их размеры. В **Placements** доступны точные координаты.
5. Чтобы правка стала общей для экземпляров, используй **Overrides → Apply All**, либо редактируй сам **Assets/ChessCards/Prefabs/Match Layout.prefab**. Изменения только в сцене оставляй как overrides.

| Блок | Что регулирует |
| --- | --- |
| Table | Положение и размер всего деревянного стола с сукном |
| Board | Игровая доска. Сохраняет квадратную форму по меньшему размеру |
| Match Status | Статус хода, очередь и оставшиеся перемещения |
| Deck / Discard / Opponent Hand | Три независимые стопки с подписями и количеством. Во время показа карты бота сброс остаётся видимым |
| Cards | Вся рука с заголовком. Карты автоматически уменьшаются под её высоту, лежат с нахлёстом и поднимаются при выборе. Большая рука занимает несколько рядов |
| Player Info | Твоя сторона или число костяшек у бота |
| Notice | Единственная контекстная подсказка, объявление карты или награда |
| Actions | Добор, пас в го, повтор партии и возврат во двор |
| Scoring | Панель подсчёта го. Для редактирования включи **Preview Layer → Go scoring** |
| Title / Back / History / Rules / Settings | Верхняя навигация и заголовок |

**Важно:** координаты блоков независимы. Увеличение `Table` само по себе не передвигает доску и руку. Схема Inspector показывает границы, итоговый вид смотри в Game. Вся эта настройка использует существующую систему IMGUI, а не Canvas/RectTransform.

В **Chess Cards → Select Royal Theme → Match Table** можно менять:

- **Match Velvet / Wood / Burgundy / Disabled** — цвет сукна, дерева, плашек и выключенной кнопки;
- **Match Cloth Texture / Match Wood Texture** — свои текстуры. Пустые поля используют встроенные процедурные поверхности;
- **Table Rim / Table Corner Radius** — толщину обода и скругление;
- **Match Backdrop Shade** — затемнение фона зала;
- **Hand Card Height** — максимальную высоту карты (при нехватке места она уменьшается);
- **Match Label Size / Match Title Size**, **Match Ornaments** — размер подписей, горизонтального заголовка и видимость декора.

Нахлёст и подъём настраиваются в прежнем **Card Hand Layout**. Фон — в **Game Room**, карточная графика — в **Cards and Pieces**, украшения — в **Illustrations**. Изменения темы удобнее делать до Play. Для отдельного оформления только этой сцены создай копию темы и назначь её в **Match Layout → Theme Override**.

Пас, результат, подсчёт го, история, правила, настройки и превращение пешки сохраняют свои действия. Заголовки и стопки не реагируют на наведение. Открытое окно блокирует управление столом; недоступный добор оформлен приглушённой коричневой кнопкой.
