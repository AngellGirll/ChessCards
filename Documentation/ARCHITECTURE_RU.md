# Архитектура ChessCards

```
Assets/ChessCards/
  Scenes/      Main (двор) и Match (партия)
  Prefabs/     ChessCards Runtime, Courtyard Layout, Match Layout
  Config/      GameBalance и RoyalTheme
  Core/        правила четырёх игр, колода, бот и данные прогресса
  Runtime/     переходы между сценами, сохранение, звук и отображение
  Editor/      редактор раскладки и меню Chess Cards
  Resources/   графика, шрифт и звук
```

## Настройка без кода

| Что поменять | Где в Unity | Как это работает |
| --- | --- | --- |
| Позиция доски, руки, кнопок или панели ремонта | Открой сцену и выбери `Courtyard Layout` или `Match Layout` в **Hierarchy** | В Inspector переключи **Landscape** или **Portrait**. Перетаскивай блоки на схеме, меняй ширину и доступные размеры за правый нижний угол. Окна редактируются на отдельных слоях **Preview Layer**. Точные координаты находятся в **Placements** |
| Раскладка по умолчанию для новых сцен | **Assets → ChessCards → Prefabs** | Открой нужный префаб в **Prefab Mode**. Настройки на экземпляре в сцене сохраняются как её собственные изменения |
| Оформление, иллюстрации, карты, фигуры, фон, шрифт и звук | **Chess Cards → Select Royal Theme** | Замени ссылки на ассеты или измени цвета. Если хочешь задавать шахматные фигуры отдельными текстурами, очисти поле **Chess Pieces Atlas**. В **Theme Override** на префабе раскладки можно назначить отдельную тему для сцены |
| Название двора и панели ремонта | **Royal Theme → Courtyard Labels** | У каждой надписи есть русский и английский варианты |
| Нахлёст и подъём карт | **Royal Theme → Card Hand Layout** | **Hand Spacing** задаёт расстояние между картами, **Hand Lift** — высоту подъёма |
| Награды, цены ремонта, начальная рука и состав колоды | **Chess Cards → Select Game Balance** | Измени поля **Restoration** и **Card Deck**. Новая партия получит обновлённую колоду |
| Режимы, паузы бота и настройки новых игроков | **Game Balance** | **Enabled Modes** задаёт порядок и доступность режимов, в том числе для рандома. Значения **Defaults for a New Save** применяются, пока игрок не сохранил собственные настройки |
| Режим для быстрого теста партии | **Match → Match Layout → Preview Mode** | Открой сцену `Match` и нажми **Play**. Сцена запускает партию в выбранном режиме, если он включён в балансе |

**Chess Cards → Open Courtyard Scene** открывает стартовую сцену. **Open Match Scene** открывает сцену партии. Для обычного запуска открывай `Main`. В **Build Profiles** должны быть обе сцены, первой идёт `Main`.

## Префабы и связи

- **ChessCards Runtime** хранит ссылки на тему, баланс и имена сцен. Единственный экземпляр сохраняется при переходе между двором и партией.
- **Courtyard Layout** и **Match Layout** хранят две раскладки и, при необходимости, переопределение темы. Сцены используют экземпляры этих префабов. Изменения в сцене сохраняются вместе с ней.
- **Core** не зависит от Unity. Он определяет легальность ходов, порядок применения карт и условия победы. **Runtime** использует эти правила и связывает их со сценами, вводом и сохранением. **Editor** добавляет инструменты авторинга.

Схема в Inspector показывает границы блоков. Итоговое оформление проверяется во вкладке **Game** в режиме **Play**. Интерфейс рисуется через IMGUI. Внутренняя раскладка списков, клеток и элементов внутри составных блоков формируется автоматически. У блока **Cards** редактируются положение и ширина, его высота задаётся внутренней раскладкой. Полный набор переводов и изменение правил самих игр остаются в коде.

Формат сохранения двора и пользовательских настроек совместим с предыдущей версией. При замене фоновых иллюстраций двора используй одинаковую композицию для обычного и восстановленного вида, чтобы участки ремонта совпадали.
