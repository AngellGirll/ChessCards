# Шахматы × карты — прототип для Unity

Игровой прототип в составе готового Unity-проекта. В нём есть игра против бота, шахматная доска, карты и восстановление двора. Название «Королевский двор» — рабочее.

Это не готовый APK/EXE. Создание проекта, запуск Unity Editor и сборка выполняются на твоём компьютере. Версия установленной Unity пока не указана. Код использует API Unity 2022.3 / Unity 6 без сторонних игровых библиотек; фактический импорт в эти редакторы здесь не проверялся.

## Первый запуск

Это сохранённое описание прототипа. Для запуска полного Git-проекта используй актуальную инструкцию [README.md](../README.md). Копировать Assets в другой проект и создавать сцену заново не требуется.

## Как играть

1. Посмотри верхнюю карту сброса.
2. Выбери подсвеченную карту того же цвета либо значения/эффекта.
3. Нажми свою фигуру. Доступные клетки подсветятся.
4. Нажми клетку назначения. Для карты 2 или 3 повтори перемещение, пока серия не закончится. Можно двигать одну фигуру несколько раз.
5. Если нет доступных карт, нажми **«Взять карту»**. Подходящую добранную карту нужно нажать, чтобы разыграть.
6. Если рука длиннее четырёх карт, листай её стрелками.
7. Поставь мат. 100 монет зачислятся сразу, один раз за партию.
8. Вернись во двор и выбери ремонт. Объект визуально изменится; монеты, победы и состояние объектов сохранятся после закрытия приложения.

Кнопка **«Правила»** доступна во дворе и в партии. Пока правила открыты, бот приостановлен. Возврат во двор во время незавершённой партии требует подтверждения и не даёт награды.

## Принятые правила

| Область | Реализация |
|---|---|
| Доска | 8×8, стандартная начальная расстановка всех фигур |
| Противник | Локальный бот; обе стороны используют одинаковые правила |
| Победа | Шахматный мат, проверяемый после каждого перемещения |
| Числовые карты | 1, 2, 3; количество последовательных шахматных перемещений |
| Рука | По 5 карт, автоматического пополнения нет |
| Совпадение | Цвет либо число; специальные карты совпадают по цвету или эффекту |
| Лимит | Одна карта за очередь |
| Добор | Только когда нет доступных карт; одна карта; подходящую можно сразу разыграть |
| Неудачный добор | Очередь переходит противнику; при шахе вместо пропуска даётся одно обязательное защитное перемещение |
| Пустая рука | Не победа; в следующую свою очередь игрок добирает карту |
| Шах | Немедленно прерывает серию и передаёт очередь противнику |
| Обмен сторон | Меняет владельцев армий и ориентацию доски; руки не меняются; затем одно перемещение новой стороной |
| Отмена | Откатывает последнее перемещение фигуры с полным состоянием доски; затем одно своё перемещение |
| Пропуск | Одно своё перемещение, после которого пропускается следующая очередь противника; если поставлен шах, пропуск отменяется |
| Колода | 72 карты: по 4 копии чисел 1–3 и по 2 копии каждого из трёх эффектов, для каждого из 4 цветов |
| Первый сброс | Всегда числовая карта; её эффект в начале не применяется |
| Повторное использование колоды | При исчерпании колоды сброс перемешивается; верхняя карта остаётся |
| Награда | 100 монет за победу; поражение/ничья без награды |
| Ремонт | Свободный порядок: скамейка 60, фонарь 100, дом 180 |

### Уточнения для краевых случаев

- Нельзя оставить своего короля под ударом или взять короля противника.
- Обмен сторон недоступен, пока любой король под шахом. Это не даёт уйти от обязательной защиты простой сменой армии.
- Отмена недоступна, если ещё не было перемещений, после отката у активной армии нет легальных ходов либо откат восстановит шах чужому королю. Последний запрет не позволяет отменить защитный ответ противника и продолжить атаку без его реакции.
- Недоступная по этим условиям специальная карта не препятствует добору.
- Отмена не возвращает разыгранные карты, монеты, владельцев армий и уже прошедшие очереди; она касается только доски. Можно последовательно отменять более ранние перемещения, если правило разрешает.
- Есть короткая/длинная рокировка и четыре варианта превращения пешки. Бот тоже может превращать пешки.
- Взятие на проходе разрешено только следующим шахматным перемещением другой армии. Любое следующее перемещение гасит возможность; розыгрыш карты или очередь без перемещения сами по себе её не гасят.
- Ничья: пат в начале очереди активной армии, два оставшихся короля или 100 перемещений подряд без взятия и движения пешек. Троекратное повторение и остальные случаи недостаточного материала пока не проверяются.
- Физические цвета фигур не меняются при обмене сторон: меняется управление ими. Доска автоматически поворачивается так, чтобы армия игрока была снизу.
- Незавершённая партия при закрытии приложения не сохраняется. Сохраняется только прогресс восстановления.

## Проверка на телефоне и ПК

В редакторе сначала проверь **Game → Aspect** с соотношениями **9:16** и **16:9**. Интерфейс выбирает вертикальную или горизонтальную компоновку и вписывает её в безопасную область экрана. В других пропорциях возможны поля по краям.

Для сборки:

1. В Unity Hub установи модуль нужной платформы у выбранного редактора. Для Android нужны Android Build Support, SDK/NDK Tools и OpenJDK.
2. Открой **File → Build Settings** (Unity 2022.3) или **File → Build Profiles** (Unity 6).
3. Выбери **Windows** / нужную настольную платформу либо **Android**, переключи платформу при необходимости.
4. Убедись, что созданная сцена прототипа первая и включена в список сцен. Команда настройки добавляет её автоматически.
5. Проверь **Active Input Handling = Input Manager (Old)**.
6. Для обычной отладки включи **Development Build**, затем **Build** / **Build And Run**.
7. На телефоне проверь нажатие карты, выбор фигуры, перемещение, переворот доски, прокрутку правил, смену ориентации и сохранение ремонта после перезапуска.

Поддержка iPhone потребует отдельной сборки iOS через macOS/Xcode и проверки на устройстве. Готовая мобильная сборка в архив не включена.

## Если что-то не запускается

| Симптом | Что проверить |
|---|---|
| Не появилось меню Chess Cards | Дождись компиляции; открой Window → General → Console и проверь красные ошибки. Убедись, что Editor/PrototypeSetup.cs находится внутри Assets/ChessCards |
| Видно интерфейс, но кнопки не нажимаются | Active Input Handling должен быть Input Manager (Old); после смены может потребоваться перезапуск редактора |
| Пустая сцена | Запусти команду Create Prototype Scene, открой вкладку Game и нажми Play |
| Фигуры или русский текст отсутствуют | Папка Assets/ChessCards/Resources/ChessCards должна содержать PNG и UI.ttf; не переименовывай её до первого запуска |
| Карту нельзя выбрать | Очередь бота, серия перемещений уже началась, цвет/значение не совпадает или эффект сейчас недоступен |
| Бот ещё не сходил | Между действиями есть пауза примерно 0,55 секунды; закрытые правила/диалог приостанавливают его |
| Ремонт не покупается | Проверь цену и баланс; один объект нельзя покупать повторно |

## Файлы

- `Assets/ChessCards/Core/ChessPosition.cs` — шахматная доска, генерация легальных перемещений, шах, рокировка, превращение и взятие на проходе.
- `Assets/ChessCards/Core/CardMatch.cs` — очередь, карты, колода, история отмен, мат/ничья и экономика ремонта.
- `Assets/ChessCards/Core/ChessBot.cs` — ограниченный поиск до двух перемещений и выбор карты. Это простой бот для проверки механики, не полноценный шахматный движок.
- `Assets/ChessCards/Runtime/ChessCardsApp.cs` — экраны, ввод, адаптация размеров, отрисовка и сохранение через PlayerPrefs.
- `Assets/ChessCards/Editor/PrototypeSetup.cs` — создание сцены через меню.
- `Assets/ChessCards/Resources/ChessCards` — шахматные иконки, шрифт и его лицензия.
- `Validation` — отдельные проверки, не попадающие в Unity-проект при копировании Assets. Для них нужен .NET 8 SDK, для самой игры он отдельно не нужен.

Менять баланс можно в `CardMatch.cs`: `RestorationProgress.Prices` и `AwardWin()`. Отрисовка цифры награды находится также в `ChessCardsApp.cs`.

## Проверки и ограничения

Подробности в [VALIDATION.md](VALIDATION.md). Здесь выполнены контрольные подсчёты шахматных ходов, проверки гибридных правил, симуляции ботов и отдельный тест переходов интерфейса/сохранения. Запуск Unity Editor, компиляция настоящими Unity-сборками и сборки под устройства здесь не выполнялись. Поэтому первый обязательный шаг после импорта — запуск в редакторе и проверка Console.

Графика двора намеренно простая, без анимаций и финальных ассетов. Есть одна повторяемая партия со стандартной расстановкой; кампании и роста сложности уровней пока нет.
